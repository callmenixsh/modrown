# Dev Workspace

A terminal-inspired React development workspace.

## Welcome to the Terminal Interface

Hello! You're now in a terminal-inspired development environment.

```
$ npm install
$ npm run dev
```

## Terminal Interface Overview

The interface displays this workspace as a terminal window with:
- System prompts and navigation
- File browsing capabilities
- Development tools integration

## Terminal Features

- `ls -la` - List files recursively
- `cd [directory]` - Navigate directories
- `cat [file]` - View file contents
- `grep "pattern" [file]` - Search files
- `find "name"` - Locate files by pattern

## Getting Started

Edit `src/App.jsx` to customize your terminal interface.
Save files to see live reload

## Modrown

A terminal-style interface for installing modpacks and collections from Modrinth

Navigation:
- `about` - Learn more about Modrown
- `modpack` - Browse and install modpacks
- `collection` - Browse and manage collections
- `help` - View available commands
